  nosbx = re-signed ad-hoc with Hardened Runtime and NO entitlements; same identifiers
  App binary SHA-256 after removing signatures: identical for both variants.
Both FIDO2 keys connected (1050:0406, 1ea8:f829). Hardware use: read-only discovery only.
Window actions: temporary in-app control (Accessibility not granted). 'probe-menu' runs the same
read-only refresh as a menu selection and checks every menu handle still resolves (never republishes).

phase; state = NSRunningApplication active/hidden + CGWindowList on-screen flag for the app's windows
(an experimental window-coverage figure was unreliable and has been removed).
